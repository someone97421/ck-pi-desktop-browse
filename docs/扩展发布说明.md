浏览器扩展 0.0.19

相对正式版 `v0.0.18`（源码 `abae99435538cf5db6ac3a6e494b2e7f803fed07`）的更新：

- 本机侧栏通过专用扩展通道自动连接新版桌面主程序，无需输入密码、配对码或手写 MCP 配置；Browse CLI 与 MCP 由主程序内置并托管。
- 服务端校验真实扩展来源与本机连接，扩展会话令牌仅在内存中流转。直接打开远控端口网页仍需密码，包括 localhost；跨机器连接继续使用主机密码。
- 修复离线 Relay 启动后卡在待配对状态的问题，并发操作共用后台自动配对任务。
- 侧栏启动先读取已保存的主程序地址，保留标签页、选文、DOM 准星引用及文件预览、下载。

下载 `browse-extension-0.0.19.zip` 后解压，在 `chrome://extensions` 开启开发者模式并「加载已解压的扩展程序」。ZIP 保留固定扩展 ID，升级时覆盖原目录后重新加载。`SHA256SUMS` 用于核对下载文件。

本机免密连接需要配套的新版 [「这是一个助手」桌面预发布](https://github.com/someone97421/CK-PI-Desktop/releases)，旧主程序没有扩展会话入口时不能使用此流程。已有明确停用插件的设置会保留，需要时在桌面重新启用浏览器连接插件。桌面安装包与扩展分别发布。
