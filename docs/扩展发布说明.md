浏览器扩展 0.0.18

- 在 Chromium 侧栏连接「这是一个助手」，使用桌面应用原始聊天界面。
- 支持标签页、选文与 DOM 元素引用；拖动输入工具栏的准星捕捉网页元素，移除旧修饰键点击入口。
- 修复 Relay 查询标签页时的访问授权与侧栏消息转发，避免重复添加元素引用。
- 补全文档、桌面主程序链接与 GitHub 手动扩展发布流程。

下载 `browse-extension-0.0.18.zip` 后解压，在 `chrome://extensions` 开启开发者模式并「加载已解压的扩展程序」。ZIP 保留固定扩展 ID，升级时覆盖原目录后重新加载。`SHA256SUMS` 用于核对下载文件。

侧栏需要配套的 [「这是一个助手」桌面应用](https://github.com/someone97421/CK-PI-Desktop) 与局域网远程控制插件；工具栏 DOM 准星及文件预览、下载需要包含对应适配器的新版主程序或插件。桌面主程序本次仍为本地测试包，未随本扩展发布。
