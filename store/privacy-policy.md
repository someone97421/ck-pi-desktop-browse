# “这是一个助手 · 浏览器”隐私政策

最后更新于 2026-11-19。

本文为扩展 0.0.21 的隐私政策草稿。正式公开前，发布者须核对数据用途、联系渠道与最终发行版，并确定生效日期。

## 运营者与适用范围

本扩展由 GitHub 用户 **someone97421** 维护，是“这是一个助手 / this-is-a-agent”桌面应用的配套浏览器扩展。

本政策说明浏览器扩展如何处理数据，以及与桌面主程序和用户配置服务之间的数据流。第三方网站、模型提供商及用户自行运行的网络主机有各自的数据处理规则；本扩展不能代替这些服务作出保留期限或模型训练方面的保证。

## 处理哪些信息

| 信息 | 何时处理 | 用途 |
| --- | --- | --- |
| 已打开标签页的标题、URL、标签页／窗口标识 | 侧栏连接及标签页列表更新时，或助手请求浏览器标签页信息时 | 显示 @ 标签页引用、定位当前页及任务页面 |
| 网页选文、DOM 元素文字、属性、HTML 摘要和子框架地址 | 用户引用文字或元素时 | 把网页上下文加入输入框与后续任务 |
| 页面文字、DOM、截图、网络及控制台等调试结果 | 主程序发起相应读取、采集或诊断操作时 | 执行用户的浏览器任务 |
| 页面交互及任务状态 | 点击、填写、导航、示范记录、人工接手等操作发生时 | 操作页面和协调任务进度 |
| 连接及本地配置 | 安装配置、配对和重连时 | 保存主程序地址、浏览器标识／显示名、调试服务令牌、分组和引用偏好 |
| 短期运行日志及会话状态 | 扩展后台运行、连接或操作失败时 | 连接恢复、状态显示与故障排查 |
| 通过侧栏输入的对话、引用和附件 | 用户在主程序提供的侧栏界面编辑、上传或发送时 | 由桌面主程序提供对话、任务执行和文件处理 |

网页内容及调试结果可能包含个人身份、通信、位置、健康、财务信息或网站会话凭据。扩展不保证对所有页面内容、截图和调试结果自动去除敏感字段。扩展不会读取完整 Chrome 历史数据库来建立广告画像，但会处理当前标签页的浏览活动信息。

## 自动行为与用户控制

打开侧栏并登录桌面主程序后，主程序会创建新的临时草稿。浏览器调试服务连接就绪后，扩展会自动接入当前支持的页面。侧栏在输入框与标签页列表就绪后，把当前页引用加入初始草稿。这个过程不会自动发送聊天消息，后续任务仍可请求连接和操作其他页面。

本扩展会在 Chrome 允许的网站及子框架中加载包内的引用拾取脚本。内容脚本的存在不等于自动上传每个网页的全文；标签页元数据同步、用户引用及任务调试是不同的数据处理步骤。

用户可以取消元素拾取、停止当前页调试或停止主程序中的任务。关闭侧栏不保证全部已建立的调试连接立即断开。要停止全部扩展活动，可在 Chrome 扩展管理页停用或卸载扩展。

## 数据发送到哪里

默认主程序地址是本机回环 `http://127.0.0.1:7878`；调试服务也默认通过本机连接工作。浏览器数据可传送到用户配置的主程序与调试服务。若配置跨机器地址，数据将经过该网络主机及相关网络路径。

桌面主程序可把用户消息、网页引用、截图及工具结果发送给用户配置的 AI 模型提供商，以完成相应任务。是否转发、发送范围及模型服务的保留／训练规则，应结合任务和所选提供商设置判断，不能理解为“数据永远不离开本机”。

本扩展不设置面向开发者的浏览活动集中上传服务，不提供广告画像或数据交易功能。用户主动向维护者提交问题时，提交的内容会由所使用的支持平台处理；不要在公开问题中附上密码、令牌、真实 Cookie 或私人网页内容。

## 使用目的与分享限制

数据仅用于用户可见的浏览器助手工作流、连接与认证、引用、页面交互、状态协调及必要的故障排查。维护者不将扩展处理的用户数据出售、用于广告定向、信用评估或与扩展单一用途无关的独立用途。

任务所需的数据可由桌面主程序交给用户选择的服务提供商。用户自行选择第三方服务时，应查看其隐私政策。本政策不承诺所有模型提供商都不保留数据或不用于训练。

本扩展对来自 Google API 的信息使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求：

> The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## 保存与删除

浏览器的本地扩展存储保存连接地址、浏览器标识、调试服务配对信息、偏好、标签组及任务辅助记录。会话存储保存短期运行状态和日志。用户在主程序提供的侧栏页面输入桌面远控账号密码，侧栏页面保存其登录令牌。浏览器调试服务使用单独的配对令牌。

清除浏览器中的扩展数据或卸载扩展可移除相应扩展存储。删除扩展不会自动删除桌面主程序已经保存的对话、引用、附件、日志，也不会撤回模型提供商已收到的数据。这些数据需分别在主程序、用户指定主机及服务提供商处管理。未规定统一自动到期删除期限。

## 传输与安全边界

桌面远控网页和侧栏使用同一套主机账号密码。扩展校验 iframe 消息来源，浏览器调试服务通过单独的配对机制建立连接。Chrome 扩展本地存储不等同于专用的加密凭据保险库。

当前默认回环主程序地址使用 HTTP；调试 Relay 使用 WebSocket，当前客户端连接形式为 `ws://`。主程序地址设置支持 HTTP 或 HTTPS，但这不代表整个调试链路都使用 TLS。本政策不声称所有连接均已加密；跨机器明文路径的发布处理决定见发行版说明，正式商店发布前需要解决相应传输安全差距。

扩展不能使浏览器保护的内部页面自动变为可访问。`file://` 页面另受浏览器文件网址访问设置限制。

## 联系与政策变更

支持与隐私问题可通过项目 GitHub Issues 提交：`https://github.com/someone97421/ck-pi-desktop-browse/issues`。涉及私密内容时，先在不含敏感数据的情况下询问可用的私下沟通方式。

当数据用途、共享范围或功能行为改变时，将更新本政策，并按适用的 Chrome Web Store 要求提供相应披露。
